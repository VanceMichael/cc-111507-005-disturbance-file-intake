# 设备录波交付来源格式

支持 COMTRADE 1999 的 ASCII、BINARY(int16 模拟量)、BINARY32 和 FLOAT32；cfg 通道声明中的 a、b、primary、secondary、P/S 及单位保存原文，数值按对应编码语义解释。数字量每16通道一字，低位在前；时间戳乘 timemult 得微秒，多采样率 endSample 是闭合端点，零时间戳可按已声明采样段恢复但需说明依据。manifest 的 recordingId 与 station/device 和文件对绑定，不按文件名前缀猜测。浮点 NaN 和整数最小缺失标记保留缺测身份；元数据无法配对不合并。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://github.com/dparrini/python-comtrade。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
